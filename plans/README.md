# Accepted plans

[Project README](../README.md) · [Documentation index](../docs/README.md)

Accepted plans define the target architecture and behavior for implementation.
They do not establish that the target is implemented or verified.

| Document | Purpose |
| --- | --- |
| [Domain architecture and implementation plan](accepted/domain-architecture.md) | Domain model, use cases, repositories, world behavior, package boundaries, and migration gates |
| [Ubiquitous language](accepted/ubiquitous-language.md) | Canonical terms, their meanings, naming rules, and consistency checks |

Read both documents before architecture work or changes to domain terminology.
The [repository instructions](../AGENTS.md) require their use in future work.

The [source architecture guide](../docs/architecture/README.md) describes the
reviewed implementation. [Feature plans](../docs/plans/README.md) contain other
scoped plans and delivery records. Use source evidence to assess current behavior
and the accepted plans to determine the target behavior.
