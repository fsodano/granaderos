# Visible loading progress

Unfinished loading belongs to the physical firearm. The hands and tactical
roster show that retained work separately from ready charges. For example,
**0 cargas · Recarga en curso: 71%** means that the next charge is unfinished;
it does not mean that the gun can fire.

The percentage describes work already paid toward the next charge. It does not
promise the cost of a later order. Posture, loading assistance and weapon rules
can change that cost. A gun with several barrels can have a ready charge and
unfinished work on the next one at the same time. The two hands keep their own
weapon's progress.

At zero AP, the work remains visible. A normal save and load retain the same
work. Loading completes only through the existing paid action. A cartridge
leaves reserve only when a charge becomes ready. A gun with no unfinished work,
including an older save with no progress field, has no loading-progress label.

This display reads the existing weapon state. It changes no action cost,
ammunition, health, enemy action or saved field. See [loading across turns](reload-progress.md)
for the established mechanic and its period adaptation.
