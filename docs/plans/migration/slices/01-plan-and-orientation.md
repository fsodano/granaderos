# Slice 1: plan and orientation

**Intent:** Describe the current architecture, remaining requirements, and
migration sequence.

## Why this slice exists

The accepted architecture in
`docs/plans/accepted/domain-architecture.md` defines the target model. The
overview describes current source behavior and remaining requirements; the
plan organizes the work, and each slice note records its scope and tests.

## What it adds

| File | Content |
| --- | --- |
| `docs/plans/migration/overview.md` | Current system context, migration results, and remaining gaps |
| `docs/plans/migration/plan.md` | Scope, slice sequence, completion criteria, branch flow, and verification strategy |
| `docs/plans/migration/slices/README.md` | Links to all migration slice notes |
| `docs/plans/migration/slices/01-plan-and-orientation.md` | This note |

It also registers the folder in the plan index at `docs/plans/README.md`.

## Source scope

This documentation slice defines no runtime behavior or source-code changes.
