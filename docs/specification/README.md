Read [version 0.1](../verification/version-0.1.md) for current delivered scope.
Complete [campaign creation and sharing](../plans/campaign-authoring.md) are
future work. Design documents describe intentions as well as existing systems;
they do not certify a finished creator platform.

- [Current game design](game-design.md): approved product contract, scope decisions and full release acceptance.

- [Original supplied design](original.txt): the original campaign, history,
  equipment and native conversion brief.
- [Expanded gameplay requirements](gameplay-expansion.md): the later JA2-style
  gameplay requirements and original acceptance checklist.

The browser-game direction supersedes the original native-engine delivery
requirement. The supplied specifications preserve the design history; their
older TODO tables are not current progress reports. Use
[version 0.1](../verification/version-0.1.md) for current scope. The
[requirement ledger](../verification/published-progress.md) and
[parity audit](../verification/ja2-parity-audit.md) retain dated row evidence and
remaining comparison requirements.

Approved [scope changes](../verification/published-progress.md#scope-changes-that-override-the-original-specification)
replace the original resource economy and elite contract restrictions. Preserve
those changes when using the original requirements.
