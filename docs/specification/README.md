# Specifications

[Documentation index](../README.md)

This index links the current product design contract, the cell-edge map format,
and the historical design specifications for Granaderos. Complete
[campaign creation and sharing](../plans/campaign-authoring.md) are future work.
Design documents describe intentions as well as existing systems; they do not
certify a finished creator platform.

- [Current game design](game-design.md): approved product design, scope decisions, and release acceptance requirements.
- [Original supplied design](original.txt): the original campaign, history,
  equipment, and native conversion brief.
- [Expanded gameplay requirements](gameplay-expansion.md): the JA2-style
  gameplay requirements for dossiers, squads, lighting, buildings, and recruitment.
- [Cell-edge wall, door, and window format](wall-edges.md): schema version 2 map
  representation shared by authored maps and templates.

The browser-game direction supersedes the original native-engine requirement.
The supplied specifications preserve the design requirements; the
[JA2 parity requirements](../requirements/ja2-parity.md) hold the active gameplay
requirements baseline.

Approved scope decisions replace the original resource economy and elite contract
restrictions. Preserve those decisions when using the original requirements.
