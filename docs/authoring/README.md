# Campaign authoring

[Documentation index](../README.md)

This index collects the user guides and plans for creating, editing,
validating, and packaging campaigns in the browser studio and through the local
folder workflow.

- [Campaign studio](campaign-studio.md) — the website workflow, portable project and installable ZIP format, with exact current limits.
- [Campaign folder format](../development/campaign-authoring.md) — manifest, content, world, maps, presentation, resources and local installation.
- [Studio acceptance plan](../plans/campaign-studio.md) — required website result and acceptance criteria.
- [Story editor](../development/story-editor.md) and [sector editor](../development/sector-editor.md) — detailed controls reused inside the studio.
- [Editor experience plan](../plans/editor-experience.md) — author workflow, keyboard, layout and recovery scope, with remaining preview limits.
- [Extend the editors](../development/editor-development.md) — contributor contracts, reusable panels and bounded local checks.

Community hosting and publication services remain separate from the local
package authoring workflow. A valid package does not prove campaign balance
or final game acceptance.
